# In October 2025, autocomplete was his sweet spot for coding, with agents for some kinds of code
> "For now, autocomplete is my sweet spot." — [[talk-2025-10-17-dwarkesh-ghosts-not-animals]] @37:33

## Context
He sees three classes of coders: those who reject LLMs entirely, which he thinks is probably no longer right; the intermediate, where he is, writing a lot from scratch with the models' autocomplete while still being the architect; and those who ask agents to implement things ([[talk-2025-10-17-dwarkesh-ghosts-not-animals]] @30:43, @31:21). Typing what he wants in English is too much typing; navigating to where the code must go and typing the first few letters gives autocomplete a very high-information-bandwidth specification ([[talk-2025-10-17-dwarkesh-ghosts-not-animals]] @33:50). For some types of code he goes to an LLM agent ([[talk-2025-10-17-dwarkesh-ghosts-not-animals]] @37:33). He places this in a continuum of programmer speed-ups, from code editors, syntax highlighting, type checking, search engines and compilers to a much better autocomplete and agents, "loopy things" that sometimes go off the rails, along what he calls an autonomy slider in which humans raise themselves in the layer of abstraction ([[talk-2025-10-17-dwarkesh-ghosts-not-animals]] @38:09, @38:48, @39:23).
