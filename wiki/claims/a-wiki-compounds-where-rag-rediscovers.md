# RAG rediscovers knowledge on every question, while an LLM-maintained wiki accumulates it
> "the wiki is a persistent, compounding artifact." — [[github-2026-04-04-llm-wiki-gist]] §The core idea

## Context
He says most people's experience with LLMs and documents looks like RAG, and that it works, but the LLM rediscovers knowledge from scratch on every question with nothing built up: a subtle question needing five documents means finding and piecing together the fragments each time ([[github-2026-04-04-llm-wiki-gist]] §The core idea). He names NotebookLM, ChatGPT file uploads and most RAG systems as working this way; that is his characterisation, not a survey ([[github-2026-04-04-llm-wiki-gist]] §The core idea). In the wiki, he says, the cross-references are already there, the contradictions already flagged and the synthesis already reflects everything read, and it keeps getting richer with every source added and question asked ([[github-2026-04-04-llm-wiki-gist]] §The core idea). Good query answers filed back as new pages compound the same way ([[github-2026-04-04-llm-wiki-gist]] §Operations). The claim is about accumulation, not that RAG fails ([[github-2026-04-04-llm-wiki-gist]] §The core idea).
