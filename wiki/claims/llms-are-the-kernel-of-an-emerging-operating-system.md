# An LLM is better thought of as the kernel process of an emerging operating system than as a chatbot
> "I don't think it's accurate to think of large language models as a chatbot" — [[youtube-2023-11-23-intro-to-llms]] @42:06

## Context
Tying his talk together, he says it is a lot more correct to think of the LLM as the kernel process of an emerging operating system, coordinating resources such as memory and computational tools for problem solving ([[youtube-2023-11-23-intro-to-llms]] @42:06, @42:38). The memory hierarchy maps over: the internet, reached by browsing, is like disk, and the context window is like RAM, a finite, precious working memory that the kernel pages relevant information in and out of ([[youtube-2023-11-23-intro-to-llms]] @43:45). He sees further parallels in multithreading, multiprocessing, speculative execution, and user and kernel space, and in proprietary operating systems against a Linux-like open ecosystem ([[youtube-2023-11-23-intro-to-llms]] @44:18, @44:52).
