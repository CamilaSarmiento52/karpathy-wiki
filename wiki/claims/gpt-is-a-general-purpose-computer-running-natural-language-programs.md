# GPT is a general-purpose computer, reconfigurable at runtime to run natural-language programs
> "GPT is a general purpose computer reconfigurable at runtime to run natural language programs" — [[talk-2023-05-19-stanford-cs25-transformers]] @59:51

## Context
In the CS25 lecture he reads this from one of his earlier tweets: where previous neural nets were special-purpose computers designed for specific tasks, the programs are now given as prompts and GPT runs them by completing the document ([[talk-2023-05-19-stanford-cs25-transformers]] @59:51). He says he really likes such analogies to computers ([[talk-2023-05-19-stanford-cs25-transformers]] @59:51). Another tweet he reads says that if you scale up the training set and use a powerful enough net like a Transformer, the network becomes a kind of general-purpose computer over text, and instead of a single fixed sequence you design the sequence in the prompt ([[talk-2023-05-19-stanford-cs25-transformers]] @1:00:30). He prefaces these tweets as written for general consumption and a bit hyped, and their original dates are not given in the talk ([[talk-2023-05-19-stanford-cs25-transformers]] @58:12).

## Related claims
- Supports [[english-is-the-new-programming-language]]: in 2023 he already frames prompts as programs that GPT runs ([[talk-2023-05-19-stanford-cs25-transformers]] @59:51); in 2025 he calls prompts programs that program the LLM and says we now program computers in English ([[youtube-2025-06-19-software-is-changing]] @03:19, @04:23). It does not extend it: the 2023 talk says nothing about everyone becoming a programmer.
