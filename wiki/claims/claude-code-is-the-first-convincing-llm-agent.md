# Claude Code is the first convincing LLM agent
> "the first convincing demonstration of what an LLM Agent looks like" — [[blog-2025-12-19-year-in-review-2025]] §4

## Context
He defines an agent as something that loops tool use and reasoning for extended problem solving ([[blog-2025-12-19-year-in-review-2025]] §4). He credits Claude Code for running on the developer's computer with its private environment, data and context, and faults cloud-container agents for missing this ([[blog-2025-12-19-year-in-review-2025]] §4). He says the distinction that matters is the booted-up machine with its context, secrets and low latency, not where the model runs ([[blog-2025-12-19-year-in-review-2025]] §4).
