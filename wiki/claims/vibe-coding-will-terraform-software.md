# Vibe coding will reshape software and jobs
> "Vibe coding will terraform software and alter job descriptions." — [[blog-2025-12-19-year-in-review-2025]] §5

## Context
He argues vibe coding helps regular people program and also lets professionals write software that would otherwise never exist ([[blog-2025-12-19-year-in-review-2025]] §5). His examples include nanochat's Rust BPE tokenizer and vibe-coded apps built just to find a single bug ([[blog-2025-12-19-year-in-review-2025]] §5).

On 2026-03-20 he says a random software engineer's default workflow for building software is completely different as of basically December, and that with code now ephemeral there will be a lot of activity in the digital space to rewire everything ([[talk-2026-03-20-skill-issue]] @02:13, @43:06). He does not use the word "vibe" in that interview, so this is evidence for the reshaping, not for vibe coding as such ([[talk-2026-03-20-skill-issue]] @02:13).
