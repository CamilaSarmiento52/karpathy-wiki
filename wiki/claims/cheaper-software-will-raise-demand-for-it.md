# He is cautiously optimistic that cheaper software will raise demand for software engineering, at least for now
> "I do have like cautiously optimistic view of this in software engineering" — [[talk-2026-03-20-skill-issue]] @42:34

## Context
Answering the host's point that demand for engineering jobs keeps increasing, he says software was scarce and too expensive, so if the barrier comes down the Jevons paradox applies and demand for software goes up ([[talk-2026-03-20-skill-issue]] @42:02). His example is ATMs, which made bank branches cheaper to run, so there were more branches and more tellers ([[talk-2026-03-20-skill-issue]] @42:02, @42:34). It is very hard to forecast, he says, but at least locally there will be more demand for software, because code is now ephemeral and can be changed and modified ([[talk-2026-03-20-skill-issue]] @43:06). Earlier he says jobs are bundles of tasks, some of which go a lot faster; people should treat AI as primarily a tool for now and keep up, while the long-term future is uncertain and a job for economists ([[talk-2026-03-20-skill-issue]] @41:29).
