# LLM GUI
His argument that text is the LLM's native format but not the human's, so LLMs need a graphical interface the way early computers did ([[youtube-2025-06-19-software-is-changing]] @12:12; [[blog-2025-12-19-year-in-review-2025]] §6).

## What he says
In the talk he says no general GUI across tasks has been invented, and chatting is like using a terminal ([[youtube-2025-06-19-software-is-changing]] @12:12). App-specific GUIs matter because reading text is effortful while seeing a red-green diff is fast, so a GUI lets a human audit a fallible system ([[youtube-2025-06-19-software-is-changing]] @19:56, @22:09).

In December 2025 he says people dislike reading text and want images, slides, whiteboards and web apps, with emoji and Markdown as the early version ([[blog-2025-12-19-year-in-review-2025]] §6). He points to Gemini's nano banana as a first hint of an LLM GUI, notable for combining text, images and world knowledge in one model ([[blog-2025-12-19-year-in-review-2025]] §6).

In his knowledge-base workflow he has the LLM render markdown files, Marp slides and matplotlib images instead of terminal text ([[x-2026-04-02-llm-knowledge-bases]] §Output).
