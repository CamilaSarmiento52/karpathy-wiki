# There's a new kind of coding I call "vibe coding"
Raw: [[raw/x/1886192184808149383]] · Original: https://x.com/karpathy/status/1886192184808149383

## Summary
A single X post naming a way of building software where you "forget that the code even exists".
He describes talking to Cursor Composer by voice, accepting all diffs without reading them,
pasting error messages back without comment, and working around bugs the model cannot fix.
He judges it fine for throwaway weekend projects and calls it "not really coding".
