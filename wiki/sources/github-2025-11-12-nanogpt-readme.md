Raw: [[raw/github/karpathy__nanoGPT]] · Original: https://github.com/karpathy/nanoGPT

Dated by the README's last commit (3adf61e); the repo itself is older.

## Summary
A November 2025 notice at the top marks the repo as deprecated and points to nanochat (§intro). nanoGPT is a short, hackable rewrite of minGPT that reproduces GPT-2 (124M) and can finetune pretrained checkpoints (§intro, §finetuning). The README walks a beginner from a character-level Shakespeare model to GPT-2 reproduction (§quick start, §reproducing GPT-2).
