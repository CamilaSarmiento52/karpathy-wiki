# I attended a vibe coding hackathon recently and used the chance to build a web…
Raw: [[raw/x/1917961248031080455]] · Original: https://x.com/karpathy/status/1917961248031080455

## Summary
A single X post announcing MenuGen and linking his blog write-up [[blog-2025-04-27-vibe-coding-menugen]] (#1). He says he built a web app with auth, payments and deployment at a vibe coding hackathon, wrote none of the code himself (Cursor with Claude and o3 did), and does not really know how it works in the conventional engineering sense (#1). MenuGen turns a photo of a menu into pictures of each item, which he finds useful for a quick visual sense of the menu (#1). What interested him more was how easy or hard it is for a non-web-developer to build and deploy a full app today, and he pastes the blog's TLDR word for word: fun as a local demo, a painful slog as a real app, with most time spent configuring services in the browser (#1).

**Note:** the TLDR in this post is the blog's text; it is cited here as a second location of the same words, not as independent evidence ([[blog-2025-04-27-vibe-coding-menugen]] §intro ¶TLDR).
